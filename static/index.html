Proxy Configuration 🌍
Each account can have its own IP from a different country. This is the most important factor for inbox placement when all accounts are on the same server.
How to set proxy per account
Click "+ Add Account" → fill Proxy field → each account gets its own IP
Per-account
Supported proxy types
SOCKS5 (best), SOCKS4, HTTP/HTTPS
socks5://user:pass@host:1080
http://user:pass@host:8080
Recommended providers
Residential proxies — one static IP per account from different cities
Bright Data
Smartproxy
Oxylabs
PySocks library
Required for proxy support — already installed if you used START.bat
pip install PySocks
Without proxy
System works fine — all accounts share your server IP. Proxy is optional but recommended for 10+ accounts.
